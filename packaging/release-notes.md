A preset librarian for the **UDO Super Gemini** and **Super 8**: store, tag and favourite your
patches (`.usg`) and performances (`.xsg`), then drag and drop them onto the synth's banks and slots.
An independent tool, not made by UDO Audio.

## Download

| Computer | File |
| --- | --- |
| **Mac** (Apple Silicon or Intel, macOS 11+) | `Super-Gemini-Librarian-…-Mac.dmg` |
| **Windows** 10 or 11 (64-bit) | `Super-Gemini-Librarian-…-Windows-Setup.exe` |
| Windows, no install | `Super-Gemini-Librarian-…-Windows-Portable.zip` (unzip, then run `Super Gemini Librarian.exe`) |

## Installing

**Mac:** open the `.dmg` and drag the app onto **Applications**. The first time you open it, macOS
says it "could not verify" the app, because the app isn't registered with Apple. Click **Done**, open
**System Settings → Privacy & Security**, and click **Open Anyway**. Allow access to the removable
volume if asked.

**Windows:** run the Setup file. If Windows shows "Windows protected your PC", click **More info →
Run anyway**. This happens because the installer isn't signed. The app needs Microsoft Edge WebView2,
which Windows 10 and 11 already include.

## Connecting the synth

Switch the Super Gemini off, hold **PATCH**, switch it on, then connect USB. A drive named
**GEMINI** appears and the librarian finds it automatically. Click **Eject** when you're done,
then restart the synth.
